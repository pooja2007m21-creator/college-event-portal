# College Event Portal

A simple, responsive single-page college event portal in HTML5, CSS3 and vanilla JavaScript. Frontend only: no backend, database or framework.

## Features
- Festival countdown
- Event cards with icon, category, date, time, venue, coordinator, View Details and Register Now
- Search, category filter and sorting (by date or name)
- Announcements with Read More
- Registration form with JavaScript validation and a success message (demo only, nothing is stored or sent)
- Responsive layout (CSS Grid, Flexbox, media queries)

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Customise
Edit the `events`, `announcements` and `FESTIVAL_DATE` values at the top of `events.js`.

## Files
`index.html`, `events.css`, `events.js`, `README.md`
